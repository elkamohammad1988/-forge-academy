## Long description (Gumroad / store listing)

A complete, production-grade website + backend for any martial-arts gym,
fitness studio or dojo.

**What it is**
- 8 polished public pages: home, schedule, pricing, coaches, contact,
  free-trial booking, thank-you, blog, 404.
- A real backend: Node + Express + SQLite, with versioned migrations.
- Member portal with sign-in, password reset, email verification, profile,
  bookings, cancel + waitlist auto-promote, Stripe billing-portal access.
- Admin dashboard with KPIs, 30-day trend chart, leads/contacts/members/audit
  tabs, lead-status workflow, role management, newsletter broadcast.
- A **live Server-Sent Events admin feed** — every lead pops up in real
  time, with optional pings to Slack / Discord / Telegram / any webhook.
- Stripe Checkout for subscriptions + Stripe Customer Portal for self-serve
  billing.
- Class capacity, waitlist, auto-promotion when someone cancels.
- Markdown-driven blog. .ics calendar download on booking confirmation.
  Refer-a-friend link generator. Cookie consent with granular settings.

**Why it's worth $2,000**
- It's done. Tomorrow you have a working gym SaaS, not a backlog.
- You own the code. No subscription, no platform fee, no vendor lock-in.
- Full per-page JSON-LD.

**What you get**
- The full repo (~50 files, ~2,500 lines of hand-written code).
- One-command Docker + Caddy stack (HTTPS, healthchecks, backups).
- Static-only fallback for zero-backend hosts (Netlify / Cloudflare Pages).
- Setup wizard (`npm run setup`) generates `.env`, seeds demo data,
  creates your first admin in under a minute.
- 40 demo leads + realistic data so screenshots and your sales calls look
  alive from day one.
- Tests with Vitest + Supertest.
- GitHub Actions CI workflow.
- README + BUILD + DEPLOYMENT + API + CONTRIBUTING + this CHANGELOG.
- 30 days of email support, 14-day money-back guarantee.

**Who it's for**
- Indie gym, dojo or studio owner who wants a real product, not a Wix page.
- Agency that builds sites for fitness clients (ask about Agency licence).
- Developer who wants a serious portfolio piece they can ship to a client.

**Tech stack**
- Node 20+, Express, better-sqlite3, Zod, JWT, bcrypt, nodemailer, Stripe SDK
- Vanilla JS frontend (no React, no build pipeline required)
- Bootstrap 5 CSS only, custom design system on top
- Docker, Caddy, GitHub Actions
